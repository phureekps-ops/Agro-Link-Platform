AgroLink Platform

พอร์ทัลสหกรณ์ — จุดรับซื้อผลผลิตจากสมาชิก บันทึกการรับซื้อ ตรวจคุณภาพและความชื้น จัดกลุ่มเป็นล็อต และชำระเงิน

หมายเหตุ: สหกรณ์ไม่สามารถสมัครสมาชิกด้วยตนเองได้ — ผู้ดูแลระบบ (Platform Ops) เป็นผู้จัดตั้งบัญชีสหกรณ์ ผ่านหน้า "จัดการสหกรณ์" เท่านั้น รหัสยืนยันตัวตนนี้จะแสดงอยู่ในหน้ารายละเอียดสหกรณ์หลังจัดตั้งแล้ว
เกษตรกร / ผู้ปล่อยกู้ / ผู้รับซื้อผลผลิต / เครื่องจักรกล / ผู้จำหน่ายปัจจัยการผลิต / ลานตลาด / ผสมปุ๋ยสั่งตัด / ผู้ดูแลระบบ?
ไปที่พอร์ทัลเกษตรกร ไปที่พอร์ทัลผู้ปล่อยกู้ ไปที่พอร์ทัลผู้รับซื้อผลผลิต ไปที่พอร์ทัลผู้ให้บริการเครื่องจักรกล/ลานตาก ไปที่พอร์ทัลผู้จำหน่ายปัจจัยการผลิต ไปที่พอร์ทัลผู้ให้บริการลานตลาด ไปที่พอร์ทัลผู้ให้บริการผสมปุ๋ยสั่งตัด ไปที่พอร์ทัลเจ้าหน้าที่ภาครัฐ ไปที่พอร์ทัลผู้ดูแลระบบ
