🧠 โมเดลคะแนนเครดิต (Machine Learning)

เดิมคะแนนเครดิตเกษตรกรคำนวณจากสูตรถ่วงน้ำหนักคงที่ (30/25/25/20%) — ส่วนนี้ให้ระบบ "ฝึก" โมเดล (logistic regression) จากประวัติสัญญา/การชำระคืนสินเชื่อจริงของเกษตรกรในระบบแทน หากข้อมูลยังไม่พอ (ต้องมีอย่างน้อย 20 ราย และอย่างน้อย 5 รายในแต่ละกลุ่ม "ดี/เสี่ยง") ระบบจะไม่เปิดใช้งานโมเดลใหม่ และเกษตรกรทุกคนจะยังคงใช้สูตรเดิมต่อไปโดยอัตโนมัติ — ไม่มีทางเสียหาย

➕ เพิ่มเจ้าหน้าที่ภาครัฐใหม่

เจ้าหน้าที่ภาครัฐ (กรมส่งเสริมสหกรณ์/กรมตรวจบัญชีสหกรณ์) มี 2 ระดับสิทธิ์: ระดับประเทศ (National) เห็นข้อมูลสหกรณ์ทุกจังหวัด และ ระดับจังหวัด (Province) เห็นเฉพาะสหกรณ์ในจังหวัดที่รับผิดชอบ — หลังสร้างบัญชีแล้ว ระบบจะสร้างรหัสเข้าสู่ระบบ (Auth Subject) ให้ท่านนำไปแจ้งเจ้าหน้าที่ท่านนั้นด้วยตนเอง (ยังไม่มีอีเมล/รหัสผ่านจริงในระบบทดลองนี้) — สิทธิ์การใช้งานปัจจุบันเป็นแบบอ่านอย่างเดียว (read-only)

🛰️ บันทึกข้อมูลดาวเทียม/Remote Sensing

หมายเหตุขอบเขต: สภาพแวดล้อมนี้ยังไม่ได้เชื่อมต่อผู้ให้บริการภาพถ่ายดาวเทียมจริง (Sentinel Hub / Google Earth Engine / GISTDA) — ผู้ดูแลระบบป้อนข้อมูลด้วยมือแทนในขั้นนี้ (source_provider = manual) โดยตารางออกแบบให้รองรับการเชื่อมต่อ API จริงในอนาคตได้โดยไม่ต้องแก้ schema ตารางนี้แยกจากข้อมูลดาวเทียมของโมดูลคาร์บอนเครดิต (AWD) ซึ่งใช้เฉพาะสถานะน้ำท่วม/แห้งเท่านั้น
