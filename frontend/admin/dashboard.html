➕ เพิ่มเจ้าหน้าที่ภาครัฐใหม่

เจ้าหน้าที่ภาครัฐมี 2 ระดับสิทธิ์: ระดับประเทศ (National) เห็นข้อมูลสหกรณ์ทุกจังหวัด และ ระดับจังหวัด (Province) เห็นเฉพาะสหกรณ์ในจังหวัดที่รับผิดชอบ — และสังกัด 1 หน่วยงาน (เช่น กรมส่งเสริมสหกรณ์ หรือ สำนักงานเศรษฐกิจการเกษตร) ซึ่งกำหนดว่าจะเข้าพอร์ทัลใดได้ — หลังสร้างบัญชีแล้ว ระบบจะสร้างรหัสเข้าสู่ระบบ (Auth Subject) ให้ท่านนำไปแจ้งเจ้าหน้าที่ท่านนั้นด้วยตนเอง (ยังไม่มีอีเมล/รหัสผ่านจริงในระบบทดลองนี้) — สิทธิ์การใช้งานปัจจุบันเป็นแบบอ่านอย่างเดียว (read-only) ยกเว้นพอร์ทัล สศก. ซึ่งจัดการรายการข้อมูล/ราคาที่ตนเองเผยแพร่ได้

🔍 รายละเอียดเจ้าหน้าที่

"พันธมิตรเพื่อการผลิต" (Productive Alliance) ตามแนวคิดนโยบาย RAP-T คือข้อตกลงร่วมลงทุน 3 ฝ่าย (ภาครัฐ / ผู้รับซื้อภาคเอกชน / สถาบันเกษตรกร) ที่ไปไกลกว่าสัญญาซื้อขาย 2 ฝ่ายทั่วไป — ใครสนับสนุนอะไร (เงิน/สิ่งของ/การค้ำประกัน/ความรู้) และใครต้องทำอะไรให้เสร็จเมื่อไหร่ตามแผนธุรกิจร่วม — ขอบเขตปัจจุบัน: ทีมงาน AgroLink (Platform Ops) เป็นผู้บันทึกแทนทุกฝ่ายก่อน (เจ้าหน้าที่ภาครัฐยังไม่มีหน้าจอให้ล็อกอินมาจัดการเอง) และการลงทุนร่วมเป็นการบันทึกเป็นข้อมูลเท่านั้น ยังไม่เดินเงินจริงผ่านระบบบัญชี (ledger) เหมือนรวมออเดอร์ประมูลร่วม — ดูรายละเอียดการออกแบบเต็มได้ที่ grant_productive_alliance.sql ในโค้ดของโครงการ

🛰️ บันทึกข้อมูลดาวเทียม/Remote Sensing

หมายเหตุขอบเขต: เชื่อมต่อ Sentinel Hub (Copernicus Data Space Ecosystem) จริงแล้วสำหรับค่า NDVI (ปุ่มด้านล่าง — ต้องตั้งค่า SENTINELHUB_CLIENT_ID/SECRET บน Render ก่อนใช้งานได้ ดู DEPLOY.md) ส่วน Google Earth Engine/GISTDA และประเภทข้อมูลอื่นนอกจาก NDVI ยังไม่ได้เชื่อมต่อจริง — ป้อนด้วยมือได้ตามปกติผ่านฟอร์มด้านล่าง (source_provider = manual) โดยตารางออกแบบให้รองรับการเชื่อมต่อ API จริงเพิ่มเติมได้โดยไม่ต้องแก้ schema ตารางนี้แยกจากข้อมูลดาวเทียมของโมดูลคาร์บอนเครดิต (AWD) ซึ่งใช้เฉพาะสถานะน้ำท่วม/แห้งเท่านั้น

🛰️ ดึงค่า NDVI จริงจาก Sentinel Hub (P7 — ของแปลงที่เลือกไว้ด้านล่าง)

เรียก Statistical API ของ Copernicus Data Space Ecosystem โดยใช้ขอบเขตแปลง (gps_boundary) ที่เกษตรกรวาดไว้ตอนลงทะเบียน ค้นหาภาพ Sentinel-2 ที่ปลอดเมฆล่าสุดในช่วง 60 วันที่ผ่านมา แล้วบันทึกเป็นข้อมูล NDVI จริง (source_provider = sentinel2_optical) — ถ้าช่วงนี้มีแต่เมฆปกคลุมทั้งหมดจะแจ้งว่าไม่พบภาพที่ใช้ได้ ไม่ใช่ error

🌊 น้ำ/ความเสี่ยงภูมิอากาศ (Agri-Map)

หมายเหตุขอบเขต: Agri-Map ของกรมพัฒนาที่ดิน (บูรณาการข้อมูลน้ำจากกรมชลประทาน) เพิ่งเปิดตัวเป็นทางการช่วง ส.ค.-ก.ย. 2569 และยังไม่มี API สาธารณะให้เชื่อมต่อ — ผู้ดูแลระบบป้อนข้อมูลด้วยมือแทนในขั้นนี้ (source_provider = manual) จากประกาศของกรมพัฒนาที่ดิน/กรมชลประทาน โดยตารางออกแบบให้รองรับการเชื่อมต่อ API จริงในอนาคตได้โดยไม่ต้องแก้ schema คำเตือนที่บันทึกที่นี่จะแสดงให้เกษตรกรในจังหวัด/อำเภอนั้นเห็นทันทีที่หน้าแดชบอร์ดของตนเอง
