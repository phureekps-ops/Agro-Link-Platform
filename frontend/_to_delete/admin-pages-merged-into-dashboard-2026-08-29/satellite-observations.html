🛰️ บันทึกข้อมูลดาวเทียม/Remote Sensing

หมายเหตุขอบเขต: สภาพแวดล้อมนี้ยังไม่ได้เชื่อมต่อผู้ให้บริการภาพถ่ายดาวเทียมจริง (Sentinel Hub / Google Earth Engine / GISTDA) — ผู้ดูแลระบบป้อนข้อมูลด้วยมือแทนในขั้นนี้ (source_provider = manual) โดยตารางออกแบบให้รองรับการเชื่อมต่อ API จริงในอนาคตได้โดยไม่ต้องแก้ schema ตารางนี้แยกจากข้อมูลดาวเทียมของโมดูลคาร์บอนเครดิต (AWD) ซึ่งใช้เฉพาะสถานะน้ำท่วม/แห้งเท่านั้น
